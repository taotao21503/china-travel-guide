## English

### About This Project

This is a static HTML replica of a China Travel Guide originally published as a Tencent Docs (docs.qq.com) document. The guide covers everything an international visitor needs to know before and during a trip to mainland China — from entry policies and mobile payment to transportation, accommodation, scenic spots, and local tips.

### Why This Exists

Tencent Docs (docs.qq.com) is a Chinese cloud document platform that requires a QQ/WeChat account to access and is often inaccessible to users outside mainland China due to network restrictions. This project mirrors the full content as a freely accessible website so that:

- Travelers outside China can read the guide before their trip
- Users without a QQ or WeChat account can access the information
- The content remains available even when the original document is unavailable

## 中文

### 项目简介

本项目是一份中国旅游指南的静态 HTML 网页版本，内容来源于腾讯文档（docs.qq.com）上发布的原始文档。指南涵盖外国游客赴华前及旅途中需要了解的一切内容，包括入境政策、移动支付、交通出行、住宿安排、景点门票及实用小贴士等。

### 项目目的

腾讯文档是中国的云文档平台，需要 QQ 或微信账号才能访问，且由于网络限制，中国大陆以外的用户往往无法正常打开。本项目将全部内容以免费、开放的网页形式镜像发布，旨在：

- 让中国大陆以外的旅行者在出发前即可查阅指南
- 让没有 QQ 或微信账号的用户也能获取相关信息
- 确保在原始文档不可访问时内容仍然可用
